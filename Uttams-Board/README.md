# Uttam's Board

A clean, minimal, Excalidraw-inspired whiteboard built with Python + Tkinter,
including an Epic-Pen-style **Screen Pen** to draw over your whole desktop.

## Run
    python3 main.py

## Optional (for Export PNG / Screenshot)
    pip install pillow

## Screen Pen (draw over desktop)
Press **F8** or click the Screen Pen button. A transparent overlay covers your
screen with a floating control panel (color, width, pen, eraser, undo, clear).
Press **Esc** or Exit to leave.
- Windows: crisp transparent ink over the live desktop.
- Linux/macOS: a light tinted overlay (full color-key transparency is not
  reliably supported there).

## Keyboard Shortcuts
Ctrl+Z Undo | Ctrl+Y Redo | Ctrl+S Save | Ctrl+O Open | Ctrl+N New
Ctrl+Shift+S Screenshot | Delete = delete selected | F8 = Screen Pen
V Select | P Pen | L Line | R Rect | C Circle | A Arrow | T Text | E Eraser

Mouse: left=draw/select/move, middle-drag=pan, Ctrl+Wheel=zoom, Wheel=scroll.
